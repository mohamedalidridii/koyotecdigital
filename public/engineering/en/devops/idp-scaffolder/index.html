Nordys Fintech

Developer platform and AI service scaffolding

A new compliant microservice in four minutes, instead of two weeks

In short

The developer describes the service they need; the platform reads the company’s architecture and security rules, then generates the complete repository: starter code, Dockerfile, Kubernetes manifests, Terraform and pipeline, already compliant.

Client
Nordys Fintech
Sector
Digital financial services
Size
350 developers, 180 microservices
  • 4 minfor a new service, instead of 2 weeks
  • 100%of new services compliant from day one
  • −70%onboarding time for new developers

The context

Nordys Fintech runs 180 microservices. Creating a service “by the book” (approved image, secrets in Vault, encrypted database, security pipeline) meant reading dozens of pages and copying templates that were sometimes outdated. New developers took weeks to find the golden path.

The challenge

  1. 01

    Architecture and security rules live in documents few people read.

  2. 02

    Templates copied from service to service drift over time.

  3. 03

    Every new service has to pass the compliance audit.

  4. 04

    The platform team can’t hand-hold every creation.

Our approach

We add a service-creation agent to Backstage. Architecture guides, security policies and reference templates are indexed. From the developer’s request, the agent finds the applicable rules and generates the complete repository, validated by the same checks as production before it is created.

The solution, step by step

  1. 01

    The request

    “A Node.js payment microservice, connected to a Postgres RDS database.”

  2. 02

    The rules found

    Architecture guide, security policy, CI/CD template: the right pages, at the right time.

  3. 03

    The repository generated

    Starter code, Dockerfile, Kubernetes manifests, Terraform and pipeline.

  4. 04

    Checked before creation

    Approved image, secrets in Vault, encrypted database, security pipeline: all green.

  5. 05

    Ready to code

    The developer writes business logic in the first hour.

Results

  • 4 minto create a complete service
  • 100%of new services compliant
  • −70%onboarding time for newcomers
  • 60services created in the first quarter

What we deliver

  • Service-creation agent in Backstage
  • Index of architecture and security guides
  • Reference templates (Node.js, Python, Java)
  • Terraform, Kubernetes and CI/CD generation
  • Compliance checks before creation

Technologies

  • Backstage
  • LlamaIndex
  • Terraform
  • Kubernetes
  • Docker
  • Vault

Timeline

10 to 12 weeks

Team

1 platform engineer, 1 AI engineer
