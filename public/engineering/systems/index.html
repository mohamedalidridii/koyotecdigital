Projet type 01 / 05

« Atlas »

IA

Un assistant qui connaît tous vos documents

Pour qui
Une entreprise de 200 personnes dont les procédures, contrats et notes internes dorment dans des milliers de fichiers.
Le problème
Trouver la bonne information prend des heures, et les nouveaux arrivants posent toujours les mêmes questions.

Ce que nous construisons

  1. 01

    Vos documents

    PDF, Word, e-mails, wiki : nous les rassemblons sans les sortir de votre infrastructure.

  2. 02

    Indexés par le sens

    Chaque passage devient un point dans un espace où les idées proches se regroupent.

  3. 03

    Une question, en langage courant

    Vos équipes posent leur question comme à un collègue.

  4. 04

    Les bons passages

    L’assistant retrouve les extraits les plus pertinents, pas seulement des mots-clés.

  5. 05

    Une réponse sourcée

    La réponse cite ses sources : on peut toujours vérifier.

Concrètement, pour vous

  • Quelques secondes

    au lieu de longues recherches dans les dossiers partagés

  • Sources citées

    à chaque réponse, pour garder la confiance

  • Vos données restent chez vous

    hébergement sur vos serveurs ou en Europe

Technologies

  • Python
  • LangChain
  • PostgreSQL + pgvector
  • LLM open source ou API
  • Docker

Délai typique

6 à 10 semaines

DevOps

Du code à la production, sans coupure ni stress

Pour qui
Une équipe produit qui met en ligne à la main, un vendredi soir, en croisant les doigts.
Le problème
Chaque mise en production est lente, risquée, et dépend d’une seule personne.

Ce que nous construisons

  1. 01

    Le code est poussé

    Chaque modification déclenche la chaîne, sans intervention humaine.

  2. 02

    Construit, testé, analysé

    Compilation, tests automatiques et analyse de sécurité, à chaque fois.

  3. 03

    Empaqueté une fois pour toutes

    L’application devient une image conteneur versionnée, identique partout.

  4. 04

    Déployé sans coupure

    Kubernetes remplace les anciennes versions une à une : vos utilisateurs ne voient rien.

  5. 05

    Surveillé en continu

    Métriques et alertes en temps réel, retour arrière automatique si besoin.

Concrètement, pour vous

  • En minutes

    des mises en production plusieurs fois par jour

  • Zéro coupure

    pendant les déploiements

  • Retour arrière

    en un clic, ou automatique

Technologies

  • GitHub Actions
  • GitLab CI
  • Docker
  • Kubernetes
  • Terraform
  • Prometheus
  • Grafana

Délai typique

4 à 8 semaines

Projet type 03 / 05

« Harbor »

Cloud

Une infrastructure qui tient la charge

Pour qui
Une boutique en ligne hébergée sur un seul serveur, qui tombe à chaque promotion.
Le problème
Au moindre pic de visites, le site ralentit puis s’arrête, et chaque minute coûte des ventes.

Ce que nous construisons

  1. 01

    Aujourd’hui : un seul serveur

    Tout repose sur une machine : si elle tombe, tout s’arrête.

  2. 02

    Décrite en code

    Toute l’infrastructure est écrite en Terraform : reproductible, versionnée, vérifiable.

  3. 03

    Répartie sur trois zones

    Serveurs et base de données sont dupliqués dans des datacenters distincts.

  4. 04

    Elle s’adapte au trafic

    Pendant un pic, de nouveaux serveurs démarrent seuls, puis s’éteignent.

  5. 05

    Sauvegardée, coûts maîtrisés

    Sauvegardes automatiques et budget suivi chaque mois.

Concrètement, pour vous

  • 99,9 %

    de disponibilité visée

  • Automatique

    la montée en charge pendant les pics

  • Facture suivie

    et optimisée chaque mois

Technologies

  • AWS
  • Azure
  • Google Cloud
  • Terraform
  • Kubernetes
  • PostgreSQL managé
  • CDN

Délai typique

6 à 12 semaines

Projet type 04 / 05

« Bastion »

Cybersécurité

Trouver les failles avant les pirates

Pour qui
Une PME qui gère des données clients sans savoir où sont ses points faibles.
Le problème
Une seule faille peut suffire : vol de données, rançongiciel, plusieurs jours d’arrêt.

Ce que nous construisons

  1. 01

    On cherche les failles

    Nous testons votre système comme le ferait un attaquant, avec votre accord.

  2. 02

    Un rapport clair

    Chaque faille classée par gravité, expliquée simplement, avec sa correction.

  3. 03

    On ferme les portes

    Mises à jour, accès, mots de passe, pare-feu : la surface d’attaque se réduit.

  4. 04

    Surveillance 24 h/24

    Les tentatives d’intrusion sont détectées et bloquées en temps réel.

  5. 05

    Vos équipes formées

    Sensibilisation au phishing : le premier rempart, ce sont vos collaborateurs.

Concrètement, pour vous

  • Priorités claires

    les failles critiques corrigées en premier

  • Alertes en temps réel

    au lieu de découvrir l’attaque des semaines plus tard

  • Conformité facilitée

    ISO 27001, RGPD, loi tunisienne sur les données

Technologies

  • OWASP ZAP
  • Nmap
  • Burp Suite
  • Wazuh
  • CrowdSec
  • MFA

Délai typique

Audit en 2 à 3 semaines, puis suivi mensuel

Data & BI

Toutes vos données, un seul tableau de bord

Pour qui
Un distributeur dont les chiffres vivent dans l’ERP, trois fichiers Excel et le CRM.
Le problème
Chaque lundi, une journée entière passe à copier des exports pour obtenir des chiffres déjà dépassés.

Ce que nous construisons

  1. 01

    Des données éparpillées

    Ventes dans l’ERP, stocks dans Excel, clients dans le CRM : rien ne se parle.

  2. 02

    Collectées chaque nuit

    Des flux automatiques extraient, nettoient et rapprochent les données.

  3. 03

    Un entrepôt unique

    Une seule source de vérité, historisée et sécurisée.

  4. 04

    Des tableaux de bord vivants

    Chiffre d’affaires, marges, stocks : à jour chaque matin, sur ordinateur ou mobile.

  5. 05

    Des alertes utiles

    L’information arrive avant que le problème ne coûte.

Concrètement, pour vous

  • Fini les exports

    Excel copiés à la main

  • À jour chaque matin

    sans intervention

  • Des décisions

    prises sur des chiffres fiables

Technologies

  • Python
  • Airbyte
  • dbt
  • PostgreSQL
  • BigQuery
  • Power BI
  • Metabase
