# Ligne Inox — Concept KOYOTEC

A fictional design office for professional kitchens and laundries, imagined by KOYOTEC for the
"Art de la différence" showcase. Names, contact details and texts are invented; the contact form is a demo.

Vite + TypeScript, three.js (brushed-steel shader with pointer ripples, a kitchen plan drawn in WebGL with the red
"marche en avant" flow line), GSAP (ScrollTrigger, SplitText), Locomotive Scroll v5. Pages are prerendered into their
HTML at build time.

```bash
npm install
npm run dev
npm run build   # the showcase build passes --base=/art-de-la-difference/ligne-inox/
npm run og      # regenerates public/og.jpg
```
